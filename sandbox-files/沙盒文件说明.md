# 这里是沙盒文件

这个目录对应沙盒里的 `/data/user_persistent_data/filebridge/sandbox-files/`。
你在手机 APP 里看到、编辑、新建、删除的，就是这里的文件。

## 怎么来的

由 `scripts/sync_to_github.py` 推到这个仓库的 `sandbox-files/` 目录，
手机 APP 通过 GitHub 的 Contents API 直接读写，不需要电脑、路由器或公网服务器。

## 怎么回沙盒

你在手机上改完，跟 AI 说一句「同步沙盒文件」，
会跑 `scripts/pull_from_github.py` 把改动回灌到沙盒持久区。

## 注意

这个仓库是公开的，这里的内容别人也能看到，别放私密文件。
沙盒里其它私人资料不会被同步过来。
